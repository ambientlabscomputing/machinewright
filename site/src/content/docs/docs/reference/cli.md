The `machinewright` command is installed with the Python package. Run any command with `--help` for the same text offline.

## `machinewright`

```text
machinewright [OPTIONS] COMMAND [ARGS]...
```

| Parameter | Description |
| --- | --- |
| `--module, -m` | Additional dotted module path(s) to import for registration, on top of [tool.machinewright] modules in ./pyproject.toml |
| `--install-completion` | Install completion for the current shell. |
| `--show-completion` | Show completion for the current shell, to copy it or customize the installation. |
